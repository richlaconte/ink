# Font licences

The glyph data in this package comes from three sources:

| Hands | Source | Licence |
|---|---|---|
| allure, casual, delight, elfin, felix, pepita, readability | [EMS SVG fonts](https://gitlab.com/oskay/svg-fonts) by Sheldon B. Michaels, converted by Windell H. Oskay (Evil Mad Scientist Laboratories) | SIL Open Font License 1.1 (`OFL-EMS.txt`) |
| hershey-script, hershey-sans, hershey-serif | Hershey vector fonts, A. V. Hershey (1967), via the EMS SVG font collection | Hershey font distribution terms: free use, with attribution to Dr A. V. Hershey retained |
| relief | [Relief SingleLine](https://github.com/isdat-type/Relief-SingleLine) | SIL Open Font License 1.1 |

The `metrics` webfonts are generated from the same data: they contain only advance widths (no outlines), so they inherit the licence of their source hand.
